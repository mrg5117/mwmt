# MWMT v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the first portable PowerShell version of MackTechs Windows Migration Tool with backup-first workflows, category rules, Windows license export, and BitLocker recovery export.

**Architecture:** MWMT is a separate repo and tool from RescueKit. The v1 script detects live/offline Windows sources, lets the operator select users and categories, copies selected data with `robocopy`, and writes logs/manifests beside the script on the tech USB.

**Tech Stack:** PowerShell 5.1+, Windows built-ins (`robocopy.exe`, `manage-bde.exe`, registry/WMI/CIM), JSON config, Node static audit tests.
